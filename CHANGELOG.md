# Changelog

All notable changes to this project are documented here.
Versions correspond to the `version` field in `fxmanifest.lua`.

## [2.0.0] - 2026-08-02

### Added

- ESX / QBX / QBCore framework bridge for money, inventory, and menu UI
- Per-shop ace permission gating (`Config.UsePermissions` + `shop.permission`)

### Changed

- Renamed from an ESX-only shop to a universal multi-framework store

## [1.0.0] - 2026-08-01

### Added

- Initial ESX marker-based general store with config-driven shop locations and items
